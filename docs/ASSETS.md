# Assets

The twelve dessert illustrations, image fallback and favicon are original local SVG assets.

- Product images are stored in public/images/ and referenced by the stable IDs in src/data/products.js.
- Run node scripts/create-illustrations.mjs to regenerate the product illustrations and fallback.
- The interface uses system fonts: Segoe UI/Arial for controls and Georgia/Times New Roman for headings.
- No third-party product photographs or remotely hosted fonts are required.
- README screenshots in docs/images/ are captures of the running application.

Illustrations represent the catalog visually and are not product photographs.
